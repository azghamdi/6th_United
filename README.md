# موقع منتدى الأمم المتحدة العالمي السادس للبيانات 2026

نسخة ثابتة جاهزة للنشر على GitHub Pages، وتحتوي على الصفحات العربية والإنجليزية وجميع الأصول المستخدمة فعليًا.

## الصفحات

- `index.html` — الصفحة الرئيسية العربية
- `about.html` — عن المنتدى بالعربية
- `index-en.html` — English home page
- `about-en.html` — English about page

## النشر على GitHub Pages

1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub.
2. افتح **Settings → Pages**.
3. اختر **Deploy from a branch**.
4. اختر فرع `main` والمجلد `/ (root)` ثم اضغط **Save**.

الموقع لا يحتاج عملية بناء أو خادمًا خلفيًا. نموذج التسجيل الحالي تجريبي ويحتاج ربطه بخدمة استقبال بيانات قبل الإطلاق الرسمي.
